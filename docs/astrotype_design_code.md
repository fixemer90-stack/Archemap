# Astrotype Design Code

## 1. Дизайн-идея

**Astrotype = карта внутренних архетипов.**

Сервис должен выглядеть не как “астро-гадалка”, а как **премиальная навигационная система для самопознания**.

Основная визуальная метафора:

```text
карта + компас + звёздная сетка + психологический профиль
```

Не использовать как базовую метафору:

```text
магия
ведьмовство
дешёвая эзотерика
гадание
предсказание судьбы
```

Правильное ощущение продукта:

```text
calm premium self-discovery
```

---

## 2. Бренд-позиционирование

Astrotype должен восприниматься как:

- спокойный;
- глубокий;
- интеллектуальный;
- премиальный;
- объяснимый;
- аккуратно символический;
- психологически ориентированный.

Ключевая формула:

> **Astrotype — это не эзотерическая гадалка, а премиальная карта самопознания: астрологическая символика, психологическая структура, объяснимые выводы и спокойный навигационный интерфейс.**

## 3. Цветовой код

| Роль | Название | HEX | Назначение |
|---|---|---:|---|
| Основной фон | Deep Space | `#17142A` | глубина, ночное небо, премиальность |
| Главный акцент | Royal Violet | `#5B3FD6` | бренд, активные элементы, CTA |
| Премиальный акцент | Soft Gold | `#D8B45A` | компас, звезда, важные маркеры |
| Вторичный текст / линии | Moon Silver | `#D8DCE8` | линии карты, подписи, вторичный UI |
| Интерактивный холодный акцент | Mist Blue | `#8DA8FF` | ссылки, hover, data highlights |
| Основной текст на тёмном фоне | Warm Ivory | `#F6F1E8` | читаемый текст, заголовки |

### Принцип использования золота

Золото должно быть **приглушённым**, не кислотным.

Плохо:

```text
яркое золото
неоновое золото
эффект казино
эффект дешёвой магии
```

Хорошо:

```text
матовое золото
тонкие золотые линии
акцент на компасе
небольшие highlight-элементы
```

## 4. Акцентные цвета по продуктовым веткам

Каждая продуктовая ветка получает свой акцент, но не превращается в отдельный бренд.

| Модуль | Акцент | HEX | Образ |
|---|---|---:|---|
| Astrotype Self | фиолетовый + золото | `#5B3FD6` / `#D8B45A` | ядро личности |
| Astrotype Love | розово-бордовый | `#B84A6B` | динамика пары, близость |
| Astrotype Child | мягкий голубой / мятный | `#6BAFBD` | бережность, развитие |
| Astrotype Career | янтарный / стальной | `#C28A2E` | роль, вектор, стратегия |

Общая база для всех модулей:

```text
тёмный фон
серебряная сетка
золотой навигационный элемент
аккуратные карточки
объяснимые блоки
```

## 5. Типографика

### Заголовки и бренд

Подходящие варианты:

```text
Cormorant Garamond
Playfair Display
Cinzel
```

Роль:

```text
архетипичность
премиальность
культурная глубина
```

### Интерфейс и основной текст

Подходящие варианты:

```text
Inter
Manrope
IBM Plex Sans
```

Роль:

```text
читабельность
современность
продуктовость
нейтральность
```

### Рекомендуемая комбинация

```text
Заголовки: Cormorant Garamond
UI: Inter
```

Такой микс даёт баланс:

```text
архетипично + современно
```

---

## 6. UI-настроение

Основные характеристики интерфейса:

```text
точный
глубокий
спокойный
премиальный
не мистический
символически-интеллектуальный
```

Продукт не должен говорить:

```text
я предсказываю тебе судьбу
```

Он должен говорить:

```text
я показываю карту твоих паттернов и основания выводов
```

---

## 7. Основные UI-компоненты

### Карточки отчёта

Карточки должны показывать не только вывод, но и основания.

Пример:

```text
Архетип: Мудрец-Структуратор
Score: 86/100
Confidence: medium-high

Основания:
— сильный Меркурий
— выраженная земная стихия
— высокий показатель рациональности
```

### Рекомендуемые UI-форматы

Использовать:

```text
профильные карты
радиальные диаграммы
оси личности
скоринговые шкалы
evidence blocks
карта архетипов
сравнительные профили
версионные отчёты
```

Избегать как основного UI:

```text
карты Таро
магические шары
ведьминские символы
кричащие предсказательные виджеты
```

## 8. Мини-дизайн-система

```text
Border radius: 16–24px
Cards: полупрозрачные, glass-like, но аккуратно
Background: radial gradient, deep violet → navy
Lines: тонкие, серебристые
Primary button: violet/gold gradient
Secondary button: transparent + silver border
Charts: radial, axis-based, не “пироги”
Icons: line icons + celestial geometry
```

### Фон

Рекомендуемый фон:

```text
deep violet → navy radial gradient
```

Пример:

```css
background:
  radial-gradient(circle at top, rgba(91, 63, 214, 0.35), transparent 40%),
  linear-gradient(180deg, #17142A 0%, #0F1224 100%);
```

### Карточки

```css
.card {
  border-radius: 20px;
  background: rgba(255, 255, 255, 0.06);
  border: 1px solid rgba(216, 220, 232, 0.18);
  backdrop-filter: blur(16px);
}
```

### Основная кнопка

```css
.primary-button {
  border-radius: 999px;
  background: linear-gradient(135deg, #5B3FD6, #D8B45A);
  color: #F6F1E8;
}
```

## 9. Иконка и логотип

Текущий концепт с компасом и астрологическим кругом подходит как первый direction, но для настоящего продукта иконку лучше упростить.

### Целевая метафора иконки

```text
минималистичный компас + орбита + звезда
```

### Требования к иконке

Иконка должна хорошо читаться в размере:

```text
64×64
48×48
32×32
```

Поэтому нужно:

```text
меньше мелких знаков зодиака
меньше текста внутри иконки
больше простой формы
один сильный символ
отдельная версия без слова Astrotype
```

### Основной символ

```text
компас-звезда в круге
```

### Версии иконки

Нужны минимум:

```text
app-icon-full-color.png
app-icon-dark.png
app-icon-light.png
favicon.svg
logo-horizontal.svg
logo-symbol.svg
```

## 10. Тональность текста

Astrotype не должен звучать как предсказательный сервис.

Не писать:

```text
Узнай свою судьбу
Кто ты на самом деле
Твой точный тип
Совместимость 99%
Тебе предназначено
```

Лучше писать:

```text
Построй карту своих архетипов
Разбери психологические паттерны
Посмотри основания каждого вывода
Исследуй отношения через две карты
Найди рабочие роли, где твой стиль раскрывается сильнее
```

---

## 11. UX-принцип explainability

Каждый важный вывод должен иметь:

```text
score
confidence
evidence
basis
version
```

Пример:

```text
Вывод:
Выражен системный стиль мышления.

Score:
82/100

Confidence:
medium-high

Основания:
— высокий показатель logic axis
— сильный Mercury influence
— выраженная Earth emphasis

Версия правил:
ruleset-personality-v1.0.0
```

Это важно для позиционирования:

```text
не “ИИ придумал”
а “система рассчитала и показала основания”
```

## 12. Дизайн-гайд по модулям

### Astrotype Self

Образ:

```text
ядро личности
внутренняя карта
самопонимание
```

Визуально:

```text
фиолетовый
золото
радиальные карты
архетипические профили
```

CTA:

```text
Построить карту личности
Открыть архетипический профиль
Посмотреть основания выводов
```

---

### Astrotype Love

Образ:

```text
две карты
динамика пары
точки притяжения и напряжения
```

Визуально:

```text
бордовый
розово-фиолетовый
парные диаграммы
overlap zones
compatibility map
```

CTA:

```text
Исследовать совместимость
Сравнить два профиля
Посмотреть динамику пары
```

Не использовать:

```text
идеальная пара
совместимость 100%
он точно твоя судьба
```

---

### Astrotype Child

Образ:

```text
бережность
развитие
родительское понимание
```

Визуально:

```text
мягкий голубой
мятный
более светлые карточки
меньше драматизма
```

CTA:

```text
Понять стиль ребёнка
Посмотреть сильные стороны
Получить бережные рекомендации
```

Важно:

```text
не ставить диагнозы
не фиксировать личность ребёнка
не делать жёстких прогнозов
```

---

### Astrotype Career

Образ:

```text
роль
вектор
стратегия
рабочий стиль
```

Визуально:

```text
янтарный
стальной
матрицы ролей
карьерные оси
role fit score
```

CTA:

```text
Найти рабочие роли
Разобрать карьерный профиль
Посмотреть сильные профессиональные сценарии
```

## 13. Что точно не делать

Не использовать:

```text
кричащий неон
слишком много знаков зодиака
магические шары
карты Таро в каждом экране
ведьминские шрифты
предсказательные CTA
дешёвые градиенты
стоковые изображения космоса
слишком много блёсток
```

Не делать продукт похожим на:

```text
гороскопный сайт 2008 года
таро-маркетплейс
астро-инфобизнес
приложение “узнай судьбу”
```

## 15. Краткая формула дизайн-кода

> **Astrotype — это точный, спокойный и премиальный интерфейс для исследования внутренних архетипов. Визуально он соединяет карту, компас, звёздную сетку и психологическую структуру. Он не обещает судьбу, а показывает гипотезы, веса и основания.**
