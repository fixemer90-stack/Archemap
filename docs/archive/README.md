# Documentation archive

This directory stores historical documentation that is preserved for reference only.

## Rules

- Archived documents are not active implementation contracts.
- Active v2 feature/story docs must live under `docs/features/E16-v2-*` and `docs/SRS/`.
- Archived v1 docs must not be linked from active roadmaps as planned work.
- Archived v1 docs must not justify keeping legacy REST endpoints, routers, DTOs, database tables or frontend routes alive.
- If a useful idea is reused from the archive, copy the relevant requirement into an active v2 document and adapt it to the v2 architecture instead of importing the old artifact by reference.

## Contents

- `v1/` — legacy Astrotype v1 feature/story documentation retained as a read-only archive.
