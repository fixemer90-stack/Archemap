# Story E10.S04: Жизненные проявления и практические рекомендации

**Feature:** [Report UX Redesign — понятный self-report](FEATURE.md)  
**Статус:** ✅ Готово

## Контекст

После объяснения астрологической основы отчёт должен переводить выводы в жизненные ситуации и действия. Эта story не трогает архетипы, соционику и advanced math.

## Что сделать

1. Создать `LifeManifestations`.
2. Покрыть области: мышление/решения, эмоции/восстановление, общение/отношения, работа/фокус.
3. Для каждой области показать: «как проявляется», «что помогает», optional «риск».
4. Создать `PracticalRecommendations`.
5. Показать: что усилить, что беречь, что не делать через силу, среда/ритм/коммуникация, мини-чеклист на неделю.
6. Разместить рекомендации выше archetype/socionics blocks.

## Критерии приёмки

- [x] Есть минимум 4 области жизненных проявлений.
- [x] Каждая область имеет «как проявляется» и «что помогает».
- [x] Рекомендации содержат конкретные действия, а не только описание черт.
