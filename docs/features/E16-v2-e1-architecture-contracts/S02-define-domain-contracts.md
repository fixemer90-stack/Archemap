# V2-E1 S02: Define v2 domain contracts

## Status

✅ Contract docs aligned

## Context

This story belongs to `V2-E1 — Architecture & contracts`.

The v2 domain contract must make the report pipeline explicit enough that later implementation stories can create schemas, repositories, builders and tests without re-deciding the architecture.

## Canonical visual sample

- `docs/design/astrotype-v2-infographic-db-report-sample.html`

## Canonical data flow

```text
Birth/profile data
→ deterministic chart calculation / adapter
→ NatalChartV2
→ normalized PostgreSQL rows
→ NatalFactV2[]
→ NatalSynthesisV2
→ ReportOutlineV2
→ SectionRenderInputV2 JSON per personality section
→ LLM ReportSegmentV2 per section
→ NatalReportV2 upper narrative assembly
→ deterministic lower calculation layer appended at bottom
```

## Required contract names

The architecture/SRS must name these artifacts:

| Artifact | Purpose |
|---|---|
| `NatalChartV2` | Clean natal chart contract: placements, houses, aspects, warnings. |
| `NatalFactV2` | Evidence-backed fact generated from chart rows/reference meanings. |
| `NatalSynthesisV2` | Deterministic themes, tensions, resources and growth vectors. |
| `ReportOutlineV2` | Section ownership plan with owned/reference/forbidden semantics. |
| `SectionPlanV2` | One personality-section plan. |
| `SectionRenderInputV2` | Builder-created JSON input for one LLM request. |
| `ReportSegmentV2` | One generated prose section with evidence ids/status. |
| `NatalCalculationLayerV2` / calculation-layer output | Deterministic lower report layer: chart indicators, tables, balances, house/aspect visuals and bottom 2x2 derived accents. |
| `NatalReportV2` | Final user-facing report: upper narrative sections plus lower deterministic calculation layer. |

## Builder contract

`segment_inputs.py` / report builder must produce JSON input for each section. It must include only:

- `section_id`;
- section purpose;
- owned themes;
- allowed reference themes;
- forbidden theme ids;
- relevant facts/evidence ids;
- already-explained summary;
- style/tone contract.

It must not include:

- unrestricted full chart dump;
- socionics, Model A or function strengths;
- deferred thematic indicator bundles as user-visible blocks;
- UI layout authority for the deterministic lower calculation layer.

## Lower calculation-layer contract

The deterministic lower layer must be generated by calculation/infographic builders, not by LLM. Current MVP lower order:

```text
1. Chart/key indicators: ASC, MC, ASC ruler
2. Planet positions table + element/modality balances
3. House emphasis + aspect network
4. Key aspects table
5. Bottom 2x2 derived accents:
   - house mode balance
   - hemisphere/orientation balance
   - quadrant balance
   - compact aspect profile
```
