# Feature E3: Profile & Chart Engine

## Цель

Астрологическое вычислительное ядро: по натальным данным строится каноническая карта, извлекаются нормализованные признаки. Детерминировано, воспроизводимо, без AI.

## Зависимости

`E2`

## Критерии приёмки

- [ ] PersonProfile CRUD (дата, время, место рождения)
- [ ] Геокодинг: строка → lat/lon/city/country
- [ ] Часовые пояса: корректный IANA TZ для любой точки
- [ ] Swiss Ephemeris: позиции планет, астероидов, точек
- [ ] Flatlib: дома (Placidus), аспекты с орбами
- [ ] ChartSnapshot: JSON-снимок карты, < 2 сек
- [ ] Нормализация признаков: значения 0.0–1.0, детерминировано
