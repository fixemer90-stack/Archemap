## О документе

«Каркас соционики» — план-конспект основ теории соционики, адаптированный для понимания структуры психических функций по Юнгу. Документ описывает 16 типов личности, модель А, интертипные отношения и научный статус соционики.

## Связь с Archemap

Соционика используется как референсный фреймворк для:
- Понимания типологических различий пользователей
- Разработки вопросов калибровки (Career survey)
- Валидации rule-based интерпретаций

Примечание: Archemap не использует соционику напрямую в scoring loop. Движок основан на астрологических данных + rule engine. Соционика — дополнительный контекст для дизайна UX и формулировок.
